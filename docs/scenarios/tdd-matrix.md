# TDD Matrix

This matrix ties the scenario documents to executable tests.

## Daily triage

- Quick focus presets narrow the level set without clearing text or time filters.
- Active filter pills are removable one by one.

## Noise control and saved views

- Filter normalization removes duplicate categories and whitespace before a view is saved.
- Saved view state can be activated and disabled without mutating the saved filter definition.

## Time focus and follow mode

- Time preset helpers anchor to the latest visible timestamp.
- Human-friendly clock-only time input resolves against the current log date.

## Keyboard first power flow

- Visible row range calculation clamps cleanly while scrolling.
- Selection-aware filter updates keep the viewport calculations stable.
